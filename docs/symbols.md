# 図記号（JIS C 0617）実装メモ

縦書きシーケンス図（P 母線が上、N 母線が下）用。

## 確認状況の凡例

- ✅ ユーザーが JIS C 0617 と照合済み
- ⚠️ 実装者の知識ベース。原本未照合

## 接点

| タイプ | 図記号 | 状況 |
|---|---|---|
| `NO` a接点 | 上下の端子線、可動片が下端から左上へ傾く | ⚠️ 傾く向き |
| `NC` b接点 | 上端子から右へ短い横線、可動片が右上へ傾き横線に触れる | ⚠️ 傾く向き |
| `PB_NO` / `PB_NC` | 接点＋破線＋押し操作記号「[」（左側） | ⚠️ |
| `CSS` / `CSNC` / `COS` / `COSL` | 接点＋破線＋ひねり操作記号（段違いのコの字） | ⚠️ 形状 |
| `RNO` / `RNC` | 普通の a/b 接点（JIS ではリレー接点を区別しない。R の文字は付けない） | ⚠️ |
| `TNO` | a接点＋限時動作記号（円弧「(」） | ⚠️ 円弧の向き・線の本数 |
| `TNC` | b接点＋限時動作記号（円弧「)」） | ⚠️ 円弧の向き・線の本数 |

COS/COSL の「↔」表示はアプリ独自の補助表示。

## 出力

| タイプ | 図記号 | 状況 |
|---|---|---|
| `COIL` / `RCOIL` | 長方形 40×20（中は空。区別はラベルで行う） | ⚠️ 縦横比 |
| `TON` オンディレイ | 長方形＋左に「×」入りの補助四角 | ✅ |
| `TOF` オフディレイ | 長方形＋左に塗りつぶしの補助四角 | ✅ |
| `SET` / `RST` | 長方形＋中に文字（JIS に該当記号なし。PLC 風） | ― |
| `GL` / `RL` / `OL` / `WL` | 丸に×（×は円周まで届く）。ラベルがないときは種別を表示 | ⚠️ |

参考: IEC 60617 では緩復帰（オフディレイ）コイルが 07-15-07（S00311）、緩動作（オンディレイ）コイルが 07-15-08。
ただし図形そのものは原本で未確認。

## 連動表示

- 同じラベルの CS/COS 同士、PB 同士を水色の点線（`C.selBd`）で結ぶ。
- 点線は相手側の操作部「[」まで（`x2-20`）。図記号の破線とは重ねない。
- CS グループと PB グループは別扱い（同じラベルでもつながない）。

## 配線

- 接続点は塗りつぶしの丸。
- 交差して接続しない配線は、横配線が円弧でまたぐ（`hopArc`）。円弧に背景色の縁取りを付け、縦配線が下をくぐって見えるようにしている。

## 原本の確認方法

- JIS: JSA Webdesk、または日本産業標準調査会（JISC）の閲覧
- IEC: library.iec.ch（クラウド環境からは 403 で拒否された）
- 規格書のページ画像があれば、それを基準に直す。
