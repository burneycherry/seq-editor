# テスト・確認手順

自動テストは Playwright + Chromium で行う。iPhone / iPad 実機での確認は手動。

## 前提

- Node.js 18 以上
- Playwright（グローバルでもローカルでも可。スクリプトが両方を探す）
- Chromium（`PW_CHROMIUM` 環境変数でパスを指定できる。未指定なら Playwright の既定ブラウザを使う）

## スクリプト

| コマンド | 内容 |
|---|---|
| `node tests/check-syntax.mjs` | `index.html` 内の `<script>` を取り出して構文チェック（ブラウザ不要） |
| `node tests/timing.mjs` | TON 3秒 / TON 1秒 / TOF 2秒 / リレー遅延 800ms の実測。許容誤差 ±0.1 秒 |
| `node tests/logic.mjs` | 通電判定の回帰テスト（b接点の連鎖、リレー経由タイマー、非表示タブ、COS 切替、発振、SET/RST、N側接点、自己保持、インターロック、遅延連鎖、回り込み検出と誤検知しないこと、同名タイマー、瞬時動作の表示、切換スイッチのラップ／ノンラップの途中状態、瞬時OFF の表示、非表示タブの短絡警告、小数の設定値） |
| `node tests/nside.mjs [out.png]` | コイルの下（N 側）に接点がある回路で、通電判定と色付けを確認 |
| `node tests/touch.mjs` | タッチ操作（タップで配置、1本指ドラッグは移動のみ、ピンチは拡大のみ、指ブレ、シム中の押しボタン保持） |
| `node tests/print.mjs [out.pdf]` | 印刷・PDF（クリック処理の中で同期的に `window.print` まで進むこと、A4 横・電源ラインごとに 1 ページ、題名＝ファイル名、シム中でも通電色を出さない、iOS の PWA では window.print を呼ばず PDF を作って共有シートに files だけを渡す・断られたら「保存・共有」で出し直す・共有できなければダウンロード・失敗したら解像度を半分にして作り直す／それでもだめならメッセージ・印刷のタイマーは設定値だけ・画像は可逆圧縮、次に触ると画面に戻る。カラー／モノクロ） |
| `node tests/render.mjs out.png` | 全図記号を並べた回路を描いてスクリーンショットを保存 |

編集のたびに `check-syntax` を、シミュレーション関係を変えたら `timing`・`logic`・`nside` を、タッチ操作を変えたら `touch` を、印刷・PDF を変えたら `print` を実行する。
見た目を変えたら `render` の画像を見て確認する。

## 手動確認チェックリスト（実機）

- [ ] iPhone Safari: 起動・素子配置・シム実行
- [ ] iPad PWA（ホーム画面に追加）: 同上
- [ ] タッチでのタップ配置・1本指ドラッグで移動・2本指ピンチで拡大縮小（誤配置しないこと）
- [ ] PDF 出力（カラー / モノクロ）：PWA では押すと共有シートが開き、プリント・ファイルに保存できる（.txt が一緒に保存されない）。共有シートが出なければ画面下の「保存・共有」。プリント画面が A4 横・1 ページずつ、「PDF に保存」できる。閉じた後に画面に触ると元に戻る（Safari・PWA）
- [ ] ライトモード表示
- [ ] 保存 → 読込で内容が一致する
- [ ] アプリを裏に回して戻ったときのタイマー挙動（復帰時にまとめて判定される）
